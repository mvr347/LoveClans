# LoveClans — новая осада (Siege)

Статус: дизайн (2026-10-08).  
Связано с: `newraids.md`, `newwars.md` (общий casus belli, модификаторы, репарации).

**Визуал / UX:** тот же уровень, что у рейдов и войн — строки босс-бара, партиклы, состояния лагерей, компасы, GUI.

---

## 0. Жанр среди трёх конфликтов

| | **Рейд** | **Осада** | **Война** |
|---|----------|-----------|-----------|
| Жанр | Ограбление точки | **Штурм периметра** | Открытый счёт |
| Объект | 1 сундук, % в зоне | **3–4 лагеря у границы** | Знамя = мораль + очки |
| Победа | Лут + уйти | **Удержать лагеря N минут** / снести все | Больше очков |
| Награда | % казны | **Короткие репарации** + дебафф земли | Полные репарации |
| Casus belli | нет | **да** | **да** |
| Компас | только атакующим → сундук | **атакующим → лагеря**; защитникам — опционально ближайший | обеим → знамя |

Осада **не** копирует:
- fill-бар «постой в круге до 100%» (рейд);
- килл-счёт как главный вин (война).

Ядро: **физические лагеря на периметре** — поставить/удержать vs снести/не дать достоять.

## 1. Условия старта

| Правило | Значение |
|--------|----------|
| Casus belli | **обязателен** (тип `siege`, цель = этот клан) |
| Капитал у обеих | да |
| Не war / siege / raid | да |
| Не союзники | да |
| Min атакующих онлайн | **2** (конфиг) |
| Min защитников онлайн | **3** (осада тяжелее рейда; не «ночник на двоих») |
| AFK > 15 мин | не в счётчике online |
| Кулдаун пары | **36 ч** (между рейдом 24 и войной 48) |
| Max concurrent sieges | 3 |
| PREPARING | **15 мин** (сбор штурма) |

PREPARING **не** отменяем из-за роста онлайна защитников (в отличие от рейда): осада — формальный штурм, защитники как раз должны успеть набежать.  
(Опционально soft-warn в чат, если онлайн защитников вырос сильно.)

## 2. Фазы

```
PREPARING (15 мин)
  → босс-бар сборов
  → casus уже сожжён при объявлении
  → в конце ACTIVE: спавн лагерей, компасы, title, siege-mode на claim

ACTIVE (20–25 мин)
  → лагеря живут / ломаются / респавнятся
  → победа атакующих: непрерывно «живые» лагеря держат hold N мин
    (hold < duration, как сейчас в коде)
  → победа защитников: таймер ACTIVE истёк, hold не набран
    ИЛИ все лагеря слишком часто сбиты и hold сброшен навсегда
      (см. §3)

END
  → репарации / модификаторы, архив, casus мести, cleanup блоков
```

Дефолт из текущего кода, уточнённый:

```yaml
siege:
  pre-start-minutes: 15
  duration-minutes: 22
  camp-hold-minutes: 10    # строго < duration
  camp-respawn-minutes: 2
  camp-count-min: 3
  camp-count-max: 4
  camp-distance-blocks: 50
```

## 3. Лагеря — механика

### 3.1 Спавн

- Вокруг **центра contested territory** (знамя или center bounding box).
- Равномерно по кругу + небольшой jitter угла (как сейчас).
- Блок: `CAMPFIRE` + PDC `siege_id`, `camp_index` (как сейчас).
- Y: highest solid + 1; если вода/лава — сдвиг по радиусу (до 5 попыток на лагерь).

### 3.2 Удержание (победа атакующих)

- «Живой» = не broken.
- Таймер hold идёт, пока **число живых лагерей ≥ threshold** (дефолт: все изначально заспавненные, или `ceil(count * 0.75)` — зафиксировать **все** для простоты v1).
- Любой снос → hold **пауза** до респавна; после респавна hold **продолжается** (не с нуля), если так честнее для атакующих.  
  **Альтернатива жёстче:** снос сбрасывает hold полностью — выбрать одно:

**Решение v1:** снос **паузит** hold; респавн **возобновляет** с того же прогресса. Полный сброс hold только если **все** лагеря broken одновременно дольше `camp-wipe-reset-seconds` (30).

### 3.3 Снос защитниками

- Удары по campfire (уже: hits + fortification levels).
- `hitsRequired = 1 + fortLevel * hits-per-level`.
- Снос → блок air, broken, таймер respawn.

### 3.4 Укрепление атакующими

- Уже есть `fortifyCamp` (каза / команда / GUI у лагеря).
- Max level 3; каждый уровень +hits к сносу.
- Визуал уровня: см. §5.

### 3.5 Респавн

- Через `camp-respawn-minutes` лагерь снова ставится **на той же координате** (если место застроено — clear radius 1 player-blocks или сдвиг на 1–2 блока).
- Fortification после полного сноса **сбрасывается** в 0 (атакующие снова платят).

### 3.6 Чего нет

- Нет % «стой в круге у лагеря» как в рейде (лагерь — объект, который **ломают**, а не capture-zone).
- Нет килл-счёта как условия победы (киллы только косвенно мешают чинить/сносить).

## 4. Награды и модификаторы

### 4.1 Победа атакующих

- **Репарации короче/меньше войны**, через ту же систему:

```yaml
siege:
  reparations:
    duration-days: 3
    daily-amount: 300
    min-daily: 50
    max-daily: 1500
```

- Модификатор на защитника: например `siege_pressure` 2–3 дня (−скорость claim / −influence tick) — опционально.
- Exp (можно ×0.75 от war-win-exp).
- Архив → у защитника just casus `revenge_siege`.

### 4.2 Победа защитников (отбили)

- Exp защитнику ×0.4–0.5.
- Короткий бафф `siege_repelled` (1–2 дня) — косметика / +influence mild.
- У атакующих just casus не выдаём автоматически (они агрессоры).

### 4.3 Мир / cancel

- Без репараций; лагеря убрать; casus уже потрачен.

## 5. Визуал / UX (уровень рейдов)

### 5.1 Босс-бар

**PREPARING** (YELLOW, обе стороны):
```
Осада [ATK] → [DEF] | Сборы 14:20
```

**ACTIVE** (YELLOW/ORANGE):
```
Осада [ATK]→[DEF] | Лагеря 3/3 | Удержание 6:12 | 18:40
Осада [ATK]→[DEF] | Лагеря 1/3 | Удержание ПАУЗА | 12:05
```

- `Лагеря A/B` — живые / всего.
- `Удержание M:SS` — прогресс hold до победы атакующих; `ПАУЗА` если live < threshold.
- Правое время — до конца ACTIVE.
- Последние 3 мин ACTIVE — бар RED pulse.

### 5.2 Action bar у лагеря

Атакующий рядом с лагерем:
```
Лагерь #2 · Уровень укрепления 1/3 · Ударов до сноса: 2
```

Защитник бьёт:
```
Снос лагеря #2 · 2/3 удара
```

### 5.3 Партиклы

| Что | Как |
|-----|-----|
| Живой лагерь | кольцо огня/smoke раз в 15–20 тиков, радиус 2 |
| Укреплённый | дополнительно enchant particles по уровню |
| Broken / ждёт респавн | редкий ash на координате |
| Hold идёт (все живы) | лёгкий soul fire по контуру claim (редко, не FPS-kill) |
| Снос | explosion emitter short + звук |

### 5.4 Компас

- **Атакующим:** компас на **ближайший живой** лагерь (обновление раз в 2–3 с); если все broken — на ближайший respawn point.
- **Защитникам:** опционально компас на ближайший **вражеский** лагерь (`siege.defender-compass: true`), чтобы контр-снос был удобнее — **рекомендуется true**.

Изымать при конце осады.

### 5.5 Glow

- Не обязателен. Если включить: **симметрия** — игроки обеих сторон glow **только в радиусе 15 блоков от любого живого лагеря** (зона штурма), не весь claim+10 как рейд.

### 5.6 Title / звуки

| Событие | Эффект |
|---------|--------|
| Старт ACTIVE | title обеим + bell/horn |
| Лагерь снесён | title обеим, номер лагеря |
| Лагерь респавн | action msg атакующим |
| Hold 50% / 90% | chat обеим |
| Победа / отбита | title + fanfare / drum |

### 5.7 LoveClaims

На ACTIVE — siege mode на contested claim (no build злоупотребления в ядре базы по политике сервера; лагеря **вне/на границе** — place camp только системой).

Запрет ставить блоки в 2 блоках от campfire для обеих сторон (анти-коробка лагеря).

## 6. GUI (точечно)

### 6.1 Объявление

Из `/diplo` карточки клана → «Осаду» (нужен casus `siege`) → подтверждение → PREPARING.

### 6.2 Укрепление лагеря

ПКМ по своему campfire (атакующий) → маленький GUI:

- Уровень 0→max, цена за уровень из казны/инвентаря.
- Лор: hits required после апгрейда.

### 6.3 Модификаторы

После осады записи в том же GUI, что война/рейд (`newwars.md` §4): дань 3 дня, `siege_pressure`, щиты не путать с raid-shield (отдельный тип или общий `post_conflict_shield` с reason).

## 7. Связь с войной (уже в коде)

Снос лагеря может давать очки **только если** параллельно идёт война тех же кланов (`war.objectives.camp-break-score`).  
В чистой осаде без войны — **только** hold/timeout, без war score.

Осаду **поверх** войны по-прежнему **запрещаем** (как сейчас взаимные проверки) — один конфликт за раз.
