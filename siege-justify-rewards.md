# Осада — дорогое обоснование и награды

Дополнение к `newsieges.md`.  
Цель: осада ощущается **тяжелее и дороже войны/рейда** — и по входу (casus), и по выходу (репарации + сразу % казны), и по аудитории (прокачанные кланы).

---

## 1. Почему осада «дороже оправдывать»

| Конфликт | Casus | Типичная цена (порядок) |
|----------|--------|-------------------------|
| Рейд | не нужен | — |
| Война | нужен | справедливый **дёшево**, шуточный **дорого** |
| **Осада** | **нужен всегда** | справедливый **заметно дороже войны**, шуточный **очень дорого** |

Осада ломает ритм сервера на ~15+20 мин, ставит объекты в мир, давит на claim. Её нельзя спамить «за оскорбление» за те же деньги, что войну.

### 1.1 Множители casus для осады

Общий пул reasonId из `newwars.md`, но **отдельные цены** для `conflictType: siege`:

```yaml
casus-belli:
  siege-cost-multiplier: 2.5    # все цены reason × 2.5 относительно войны
  # или явный override:
  siege:
    just-reasons:
      revenge_raid:  { cost: 150, ttl-days: 14 }   # война была ~50
      revenge_war:   { cost: 150, ttl-days: 14 }
      revenge_siege: { cost: 100, ttl-days: 14 }  # чуть дешевле «месть за осаду»
      unpaid_tribute:{ cost: 80,  ttl-days: 21 }
    frivolous-reasons:
      insult:        { cost: 6000 }
      dislike:       { cost: 6000 }
      looked_wrong:  { cost: 7500 }
      bad_fashion:   { cost: 7500 }
      land_envy:     { cost: 9000 }
      drunk_dare:    { cost: 5000 }
```

Дополнительно при оформлении у Гильдмастера для осады:

- **Сбор с казны клана** (не только карман лидера): `siege.declare-treasury-fee` (фикс или % от казны атакующего), чтобы шуточная осада била по банку.
- Опционально: расход **1–2 upgrade points / spirit** — только если экономика клана это переварит.

Лор предмета casus осады:

```
Казус белли: Осада · Месть за войну
Цена оформления была высокой.
Цель: [DEF] · Тип: Осада
```

### 1.2 Ограничение по уровню клана

Осада — контент **сильных / прокачанных** кланов, не новичков после создания.

```yaml
siege:
  min-attacker-clan-level: 5
  min-defender-clan-level: 4
  # нельзя осаждать «младенцев»; нельзя объявлять осаду кланом ниже порога
  level-gap-max: 8
  # если цель на 8+ уровней ниже атакующего — отказ (не фарм слабых осадой)
  # если цель намного сильнее — разрешено ( annals / риск )
```

| Проверка | Эффект |
|----------|--------|
| Уровень атакующего &lt; min-attacker | «Клан слишком слаб для осады» |
| Уровень защитника &lt; min-defender | «Цель ещё не готова к осаде» (защита нубов) |
| attacker.level − defender.level &gt; level-gap-max | «Нельзя осаждать слабейших ради лёгкой дани» |

Рейд остаётся инструментом давления на любых (с online-гейтами).  
Война — средний порог (можно `min-clan-level: 3` отдельно).  
**Осада — верхняя полка.**

### 1.3 Кулдаун и лимиты

Уже в `newsieges.md` кулдаун пары 36ч. Дополнительно:

```yaml
siege:
  max-sieges-per-clan-per-week: 2    # как атакующий
  max-times-sieged-per-week: 2       # как защитник
```

Вместе с дорогим casus это убирает «осада каждый день».

## 2. Награды при победе атакующих

Не только репарации «на дни», но и **сразу** кусок казны — как трофей штурма (не механика рейда во время ACTIVE).

### 2.1 Пакет награды

| Часть | Когда | Что |
|-------|--------|-----|
| **Мгновенный трофей** | в момент ATTACKER_WIN | % денег казны + % слотов предметов → атакующим |
| **Репарации** | N игровых дней после | ежедневная дань (как война, но короче/меньше) |
| **Exp / влияние** | сразу | multiplier |
| **Модификатор** | N дней | дебафф на защитника (pressure) |
| **Casus мести** | у защитника | `revenge_siege` (дешёвый для *войны*, для повторной *осады* всё ещё дороже) |

### 2.2 Мгновенный трофей (сундук/казна)

Snapshot казны защитника в момент победы:

```yaml
siege:
  instant-loot:
    money-percent: 25          # меньше рейда (рейд ~40), но сразу + дань потом
    item-slot-percent: 20
    min-money: 0
    delivery: "leader_or_gui"  # лидеру в инвентарь / GUI «трофеи осады» на 5 мин
```

Отличие от рейда:

- В рейде лут **во время** ACTIVE у точки, extract, online-гейты.
- В осаде лут **только после победы hold**, без сундука-entity на карте; это **приз за прорыв**, не мини-игра ограбления.

Если казна почти пуста — игроки всё равно получают репарации на дни (долг вперёд).

### 2.3 Репарации (после осады)

```yaml
siege:
  reparations:
    duration-days: 3
    daily-amount: 300
    # опционально scale от уровня защитника:
    daily-per-defender-level: 40   # +40 за уровень цели
    min-daily: 100
    max-daily: 2000
```

Итого сильный клан-цель = жирнее дань и жирнее instant % (percent от большой казны).

### 2.4 Масштаб от уровня

```yaml
siege:
  rewards-scale-with-level: true
  instant-loot:
    money-percent-base: 20
    money-percent-per-level: 0.5   # +0.5% за уровень защитника, cap 35%
    money-percent-cap: 35
```

Атаковать прокачанных **выгоднее**, но casus и риск (min online, hold) выше — не бесплатный фарм.

## 3. Победа защитников

- Без отъёма казны атакующих (или символический `defend-bounty` из стейка, если позже введём стейк).
- Exp + короткий бафф `siege_repelled`.
- Атакующие **не** получают partial instant loot.

---

## 4. Гильдмастер — копирайт/UX

В GUI оформления для вкладки **Осада**:

- Предупреждение красным: `Осада дороже войны. Нужен сильный клан (ур. ≥5).`
- Серые reason'ы с ценой уже **с учётом siege multiplier**.
- Если уровень клана низок — кнопка Осада заблокирована в diplo и у ГМа.

## 5. Сводка «вход / выход»

```
ВХОД:  casus ×2.5+ · fee с казны · ур. клана · недельный лимит · 36ч пара
ПРОЦЕСС: 15 мин сборы · лагеря · hold 10 мин · снос/респавн
ВЫХОД:   25%± казны сразу · дань 3 дня · дебафф · exp · месть-casus жертве
```

Рейд: дешёвый вход, лут в бою, щит.  
Война: средний casus, только дань на дни, очки.  
Осада: **дорогой вход**, **сразу казна + дань**, только для прокачанных.
