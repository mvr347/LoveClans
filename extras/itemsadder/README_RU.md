# LoveClans — пакет осадных лагерей

Скопируйте папку contents/loveclans в plugins/ItemsAdder/contents/loveclans, объединяя существующие данные, затем соберите ресурспак через /iazip.

Вместе с LoveClans 1.6.0 модели автоматически отображают состояния осады. Костёр, знамя, декоративная бочка, а у башни — физические опоры и лестницы управляются самим LoveClans. Ручная установка предметов через /iaget создаёт только мебель ItemsAdder.

Первые пять моделей исходного архива сохранены. Модель башни и её Blockbench-исходник адаптированы для проходимого IV уровня. Подробности установки, координат, восстановления осад и ограничений — в INTEGRATION_RU.md.

vanilla-placement — исходные вспомогательные файлы для ручной расстановки первых пяти вариантов. Их не нужно выполнять для автоматических лагерей; они не описывают физическую схему новой башни.
