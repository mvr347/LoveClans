# LoveClans — новая война, casus belli, репарации, модификаторы

Статус: дизайн (2026-10-08).  
Связано с: `newraids.md` (рейды), осада — отдельно, но делит casus belli и модификаторы.

**Визуал / UX:** тот же уровень детализации, что у рейдов — строки босс-бара, партиклы, звуки/title, состояния объектов на карте, раскладка GUI (не «сделайте красиво» в одном предложении). См. §1.4, §3.3–3.4, §4.2, §5.2.

---

## 0. Три конфликта — разные жанры

| | **Рейд** | **Осада** | **Война** |
|---|----------|-----------|-----------|
| Жанр | Ограбление точки | Штурм периметра | Открытый конфликт |
| Победа | Лут + уйти | Удержать лагеря | **Счёт** / мир / сдача |
| Награда | % казны с сундука | трофеи / давление на землю | **Репарации (дань)** на N игровых дней |
| Объект на карте | 1 сундук, % захвата | 3–4 лагеря | Знамя = мораль, **не** win/disband |
| Casus belli | не требуется (или лёгкий) | **да** | **да** |
| Письма кланов | — | — | **вырезаны** |

Война **без** наград с сундука и без disband.

## 1. Война — геймплей

### 1.1 Старт

- PREPARING (сборы) → ACTIVE (бой на таймере).
- Нужен предмет **Casus Belli** (см. §3) — тратится при объявлении.
- Min online, капитал, не союз, не другой конфликт, кулдаун пары — как в балансе ниже.
- Эскроу «ставки банка» **не обязателен**; главный приз — **репарации**, не сундук.

### 1.2 Очки

| Источник | Очки | Заметки |
|----------|------|---------|
| Убийство врага | 1–3 по рангу | recruit → leader |
| Стрик 3 / 5 | +2 / +5 | разово за стрик |
| Доминирование contested claim | тик раз в N сек | своих **строго больше** врагов, минимум 2 своих; soft-cap «эффективных» голов (напр. max 5) |
| Подавление знамени | крупный бонус **раз** (или после починки снова) | не капитуляция |
| Убийство лидера / стража | +5 / +3 | |

**Нет:** progress-bar «постой у точки до 100%» (это рейд).  
**Нет:** лагерей (это осада).

Доминирование: 0 vs 0 и ничья по числу в claim → **0 очков**.

### 1.3 Знамя

- N ударов → «сбито»: +очки атакующим, дебафф защитникам (×0.5 очки доминирования и/или запрет home на M минут).
- Защитники **чинят** знамя (ресурсы + время у знамени).
- **Не** disband, **не** авто-победа по таймеру удержания знамени.

### 1.4 Компас / HUD / glow / визуал

Уровень детализации — **как в `newraids.md`**: конкретные строки босс-бара, партиклы, звуки, состояния знамени, симметрия сторон.

#### Компас
- Выдаётся **обеим** сторонам при переходе PREPARING → ACTIVE.
- Цель: блок знамени contested territory (если есть), иначе центр claim.
- Тот же тип item, что war-compass сейчас; изымается при конце войны.
- Не односторонний «охотничий» компас рейда.

#### Босс-бар

**PREPARING** (обе стороны, цвет RED):
```
Война [ATK] → [DEF] | Сборы 12:40
```
Прогресс бара = оставшееся время подготовки. За 1 мин — chat/title warning обеим.

**ACTIVE** (обе стороны):
```
Война [ATK] 14 — 11 [DEF] | 28:40 | Знамя: цело
Война [ATK] 14 — 11 [DEF] | 28:40 | Знамя: СБИТО
```
- Цвет бара: RED, пока идёт бой; YELLOW последние 5 мин (ENDGAME soft); GREEN на секунду при своём килле (опционально pulse).
- Обновление счёта при каждом изменении очков (не реже раза в 2 с при dominance-тиках).

**Конец** — title + subtitle обеим (победа / поражение / ничья / мир), бар скрыть.

#### Action bar (только в contested claim)
```
Доминирование: ATK 3 — 1 DEF  |  +2 очка через 8с
```
или пусто, если нет преимущества. Не дублировать весь босс-бар.

#### Партиклы
| Что | Где | Кому |
|-----|-----|------|
| Контур contested claim | границы claim, раз в 20–40 тиков | участникам войны в радиусе обзора |
| Зона знамени (если бьют / чинят) | кольцо 2–3 блока у знамени | всем рядом |
| Удар по знамени | crit/damage burst на блоке | всем рядом + звук |
| Знамя сбито | дым / ash, реже | всем в claim |
| Починка | happy villager / enchant | чинящим и рядом |

Не копировать «цилиндр захвата %» рейда — у войны нет fill-бара точки.

#### Состояния знамени (визуал)
| Состояние | Вид |
|-----------|-----|
| Цело | обычный clan banner |
| Под ударом | лёгкие трещины / overlay (block display или dust) |
| Сбито | замена на damaged banner / серый wool + флаг «broken» в PDC территории; партиклы ash |
| Чинится | прогресс на action bar чинящего: `Починка знамени 45%` |

#### Glow
- **Симметрия:** glow у игроков **обеих** сторон, только пока они **внутри contested claim**.
- Вне claim — без glow (в отличие от рейда: там glow атакующих в claim+10).
- Либо `war.attacker-glow.enabled: false` по умолчанию, если на сервере слишком шумно.

#### Звуки / title
| Событие | Эффект |
|---------|--------|
| Объявление / старт ACTIVE | title обеим + horn/wither-ish short |
| +очки за килл | click/orb своему клану |
| Доминирование-тик | низкий pling стороне в плюсе |
| Знамя сбито | wither break + title обеим |
| Знамя починено | anvil use + title |
| Конец войны | fanfare / drum по исходу |

#### Подсветка claim
На ACTIVE — `setSiegeMode` / border display LoveClaims как сейчас, чтобы обе стороны видели фронт. Не зона «ограбления», а **линия фронта**.

### 1.5 Исходы


| Исход | Эффект |
|-------|--------|
| Победа по очкам | Победитель получает **репарации** с проигравшего (§2); exp/влияние; win/loss в архив; **casus «месть»** у проигравшего на победителя |
| Ничья | Без репараций (или урезанные по конфигу) |
| Мир (PeaceOffers) | Без авто-репараций, если не прописаны в условиях мира |
| Сдача лидера | Как поражение → полные репарации |
| Cancel / disband стороны | Cleanup, без репараций |

## 2. Репарации (дань)

Вместо лута из сундука войны.

### 2.1 Суть

Проигравший **N игровых дней** платит дань победителю:

- периодическое списание из **казны** клана-должника (деньги LoveEconomy / chest money);
- если казна пуста — долг **копится** (недоимка) или частичная оплата + штраф-модификатор;
- в GUI модификаторов видно: кому, сколько в день, сколько дней осталось, недоимка.

### 2.2 Параметры (конфиг)

```yaml
war:
  reparations:
    duration-days: 5              # игровых дней (серверных календарных или tick-day — один источник правды)
    daily-amount: 500             # фикс
    # или daily-percent-of-loser-treasury-snapshot: 5
    min-daily: 100
    max-daily: 3000
    on-missed-payment: accrue     # accrue | skip | break-treaty
    max-arrears-days: 3           # после N пропусков — авто casus / можно объявить войну «за долг»
```

Снапшот казны в момент поражения можно использовать только для расчёта daily, дальше платят фикс.

### 2.3 Связь с новой войной

- Пока идут репарации: должник = «данник», победитель = «сюзерен» (только ярлык в модификаторах, не полный вассалитет).
- **Неуплата** (недоимка ≥ порога) → у сюзерена появляется **дешёвый casus belli** «Неуплата дани».
- Данник может объявить войну сюзерену **дорогим** или местью-casus, если тот его рейдил/осаждал раньше — политика на усмотрение игроков.
- Победа в новой войне: снимает/переворачивает репарации (кто выиграл — тот получает дань).

### 2.4 Осада

Осада тоже может навешивать репарации или отдельный модификатор (короче/меньше, чем война) — единообразно через систему модификаторов (§4).

## 3. Casus belli («казус белли»)

Особый предмет (ItemsAdder / PDC), без которого **нельзя** объявить **войну** и **осаду** (рейд — по `newraids.md`, без CB или с отдельным лёгким правилом).

### 3.1 Где оформить

NPC **Гильдмастер** (уже есть в LoveClans):

- GUI «Оформить повод к войне / осаде».
- Выбор цели (клан), типа конфликта (война | осада), списка доступных поводов.
- Оплата → выдача предмета в инвентарь лидера/дипломата.
- Предмет **одноразовый**, привязан к `targetClanId` + `conflictType` + `reasonId` (PDC).

### 3.2 Типы поводов

#### A. Справедливые (дешёвые) — «месть / долг»

Появляются автоматически, если в архиве/модификаторах есть основание:

| ID | Условие | Цена |
|----|---------|------|
| `revenge_raid` | цель недавно зарейдила ваш клан | дёшево |
| `revenge_war` | проиграли им войну (или они вам — зеркало политики) | дёшево |
| `revenge_siege` | недавняя осада | дёшево |
| `unpaid_tribute` | недоимка репараций вам | дёшево |
| `broken_peace` | нарушили мир/эмбарго по правилам сервера | дёшево |

Срок жизни повода: например **7–14 игровых дней** с события, потом сгорает.

#### B. Ничтожные / шуточные (дорогие)

Всегда доступны, без истории:

| ID | Пример текста |
|----|----------------|
| `insult` | «Оскорбление чести» |
| `dislike` | «Просто не нравятся» |
| `looked_wrong` | «Криво посмотрели на знамени» |
| `bad_fashion` | «Уродские щиты» |
| `land_envy` | «Зависть к землям» |
| `drunk_dare` | «Пьяный спор в таверне» |

Цена в разы выше справедливых (золото / влияние / оба).

### 3.3 Предмет — визуал

Уровень как у рейдовых/клановых item'ов (ItemsAdder + лор MiniMessage):

**Справедливый (месть)** — пергамент / свиток с красной печатью:
```
Казус белли: Месть за рейд
────────────────────────
Цель:  <red>[DEF]</red>
Тип:   Война
Повод: Месть за набег
Годен: 12 дн.
────────────────────────
Право объявить войну
у Гильдмастера оформлено
```

**Ничтожный** — тот же шаблон, серая/золотая печать, в лоре курсив «Повод сомнительный, но оплачен».

PDC: `loveclans:casus_belli` → targetId, conflictType (`war`|`siege`), reasonId, expiresAt.

Enchant glow на справедливых (короткий TTL визуально «горит»).

При `/clan war declare` / осаде: проверка в инвентаре актора, валидность цели и типа, consume + звук book page / goat horn short.

Без предмета → отказ + кликабельный хинт «Оформите повод у Гильдмастера».

### 3.4 GUI Гильдмастера «Оформить повод»

Как рейдовый/контрактный GUI — не список в чате:

1. **Выбор типа:** Война | Осада (две крупные иконки).
2. **Выбор цели:** список кланов (тег, цвет щита, отношение).
3. **Поводы:** слева «Справедливые» (зелёная рамка, цена малая, серые если нет основания), справа «Прочие» (серая рамка, цена высокая).
4. **Подтверждение:** итоговая карточка + списание монет + выдача item.

Пустые справедливые слоты: лор «Нет основания (нужен недавний рейд/война/долг)».

### 3.5 Админ

`/loveclansadmin casus give <player> <targetTag> <war|siege> <reasonId>` для тестов.

## 4. Модификаторы клана (новое GUI)

### 4.1 Вход

Главное меню клана → кнопка вроде **«Модификаторы»** / при клике на блок модификаторов → **новое GUI**, не простыня лора на одном предмете.

### 4.2 Содержимое и визуал GUI

**Размер:** chest 54 (или 45) в стиле остальных LoveClans меню (рамка glass, заголовок).

**Шапка:** `Модификаторы клана [TAG]` + lore «бафы, дебафы, дань, щиты».

**Слоты-карточки** (один модификатор = один item):

| Тип | Иконка (пример) | Лор |
|-----|-----------------|-----|
| Репарации (долг) | gold_ingot / custom coin | Дань → `[ABC]` · `500/день` · `осталось 3 дн.` · `недоимка: 0` |
| Репарации (доход) | emerald | Дань с `[XYZ]` · собрано за период · осталось дней |
| Щит после рейда | shield | `Нельзя быть целью рейда` · `11ч 20м` |
| Дебафф войны/осады | spider_eye | `−доминирование` / `slow claim` · дней |
| Бафф победы | golden_apple | `+exp / +control` · дней |
| Доступный casus | paper (как предмет CB) | `Месть на [TAG]` · `до …` · `цена у ГМа: 50` |

- Истёкшие не показываются (или серый «архив» на последней странице — опционально).
- Клик по дани → мини-экран «История платежей» (последние N списаний: день, сумма, ok/miss).
- Пустой список: один item «Нет активных модификаторов».

Прогресс «дней» — и в лоре, и в custom model data / durability bar, если удобно для IA.

### 4.3 Хранение

Таблица / store `clan_modifiers`:

- `id`, `clan_id`, `type`, `payload` (JSON: otherClan, amountDaily, …), `started_at`, `ends_at`, `stacks` optional.

Тики раз в игровой день: списание репараций, истечение щитов/бафов, выдача/сжигание casus-флагов в логике Гильдмастера.

## 5. Меню дипломатии — красивее

Текущее: эмбарго, блокада, письма, мир.

### 5.1 Вырезать

- **Письма между кланами** (`ClanLetter`, `sendLetterAsync`, GUI писем, storage letters) — **полностью убрать** из продукта.
  - Код: `DiplomacyManager` §писем, model `ClanLetter`, storage methods, GUI-кнопки, messages `diplomacy.letter.*`.
  - Не заменять внутри LoveClans другой почтой (есть LoveTweaks «Королевская почта» — вне скоупа кланов).

### 5.2 Структура нового `/diplo` GUI (уровень рейдов/контрактов)

Единый стиль LoveClans: glass-рамка, заголовок MiniMessage, иконки IA где есть, без простыней чата.

**Экран A — список**

- Заголовок: `Дипломатия`.
- Слоты кланов: щит/цвет клана + тег.
- Лор слота: `Союз` / `Нейтрал` / `Враг` / `Вы платите дань` / `Вам платят дань` + короткий статус конфликта (`Война` / `Осада` / `—`).
- Пагинация, если кланов много.
- Отдельные кнопки низа: `Эмбарго (список)` · `Блокады` · `Закрыть`.
- **Писем нет.**

**Экран B — карточка клана** (клик по слоту)

```
[Иконка щита]  [TAG]  Полное имя
Отношение: Союз / …
Влияние: …
────────────────
[Союз/Разорвать] [Эмбарго] [Блокада]
[Объявить войну] [Осаду]   [Мир]     ← мир только если активный конфликт
────────────────
Дань: нет / платим 500/день · 3 дн.
Casus на них: есть месть / нет
Последние конфликты:
  · Война 2026-09-01 — поражение
  · Рейд 2026-09-12 — победа (как жертва)
```

- Кнопки опасные (война, блокада, разорвать союз) → **Экран C «Подтверждение»** с Yes/No и кратким итогом.
- «Объявить войну/осаду»:
  - нет подходящего casus в инвентаре → кнопка серая, лор `Нужен казус белли · Гильдмастер`;
  - есть casus на эту цель и тип → кнопка яркая (enchant), лор показывает reasonId.

**Обратная связь**
- Успех действия — звук + title короткий, не только chat.
- Ошибка — тот же паттерн messages, что в рейде/войне.

## 6. Конфиг (фрагмент войны + CB + репарации)

```yaml
war:
  pre-start-minutes: 15
  duration-minutes: 45
  min-online: 3
  cooldown-hours: 48
  max-concurrent: 3
  banner-break-hits: 8
  banner-suppress-score: 25
  banner-repair-seconds: 60
  objectives:
    control-score: 2
    control-tick-seconds: 20
    control-min-members: 2
    control-soft-cap: 5
  reparations:
    duration-days: 5
    daily-amount: 500
    min-daily: 100
    max-daily: 3000
    on-missed-payment: accrue
    max-arrears-days: 3

casus-belli:
  required-for:
    war: true
    siege: true
    raid: false
  just-reasons:
    revenge_raid: { cost: 50, ttl-days: 14 }
    revenge_war: { cost: 50, ttl-days: 14 }
    revenge_siege: { cost: 50, ttl-days: 14 }
    unpaid_tribute: { cost: 25, ttl-days: 21 }
  frivolous-reasons:
    insult: { cost: 2000 }
    dislike: { cost: 2000 }
    looked_wrong: { cost: 2500 }
    bad_fashion: { cost: 2500 }
    land_envy: { cost: 3000 }
    drunk_dare: { cost: 1500 }

modifiers:
  tick-hour: 0   # серверный час списания дневных эффектов
```

## 7. Порядок реализации

1. **Вырезать письма** (DiplomacyManager + storage + GUI + messages).
2. **Модель модификаторов** + store + дневной tick (репарации, щиты, TTL casus-флагов).
3. **GUI «Модификаторы»** из главного меню клана.
4. **Casus belli**: предмет, Гильдмастер GUI, consume при war/siege start.
5. **Война**: убрать disband/banner-win; очки; suppress знамени; репарации при победе; архив → just casus.
6. **Дипломатия GUI** redesign без писем, с карточками и связкой CB/репараций.
7. Осада: consume CB + опционально свои репарации/модификаторы через ту же систему.

## 8. Явно не делаем в войне

- Награды предметами/деньгами **из сундука** в момент победы (это рейд).
- Disband проигравшего.
- Односторонний «стейнд на точке до 100%» как единственный вин.
- Лагеря по периметру (осада).
- Клановые письма.
